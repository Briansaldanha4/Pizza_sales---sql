# 🍕 Pizza Sales SQL Analysis

## 📌 Project Overview

This project analyzes a **pizza sales dataset using SQL** to understand sales performance, customer ordering patterns, product performance, and revenue contribution.

The project demonstrates practical SQL skills used in **data analysis and business reporting**.

---

## 🎯 Business Objectives

The analysis aims to answer questions such as:

* How much total revenue was generated?
* How many orders were placed?
* How many pizzas were sold?
* What is the average order value?
* Which pizzas generate the highest revenue?
* Which pizza categories perform best?
* What are the busiest ordering hours?
* How does sales performance change over time?
* What percentage of total revenue comes from each pizza?
* What are the top-performing products?
